# izzna

izzna 是一個以繁體中文輔助的韓語聊天練習原型。選擇日常情境，用自己的話與情境角色聊天；需要幫助時再打開提示或詞語解析。

## 已完成的操作

- 選擇四個共用聊天頁的情境、輸入並送出訊息；查看或收合回覆方向與單字、文法、句型提示。
- 在輸入框附近開啟「查韓文」，以中文查詢詞語；查詢不會送出訊息或清除草稿。
- 草稿中的 `[中文]` 可點擊查詢，必須主動選擇詞形才替換標記；未處理的標記會阻止傳送。填入後請自行確認整句詞尾。
- 手機與桌面版面、鍵盤操作及關閉詞語解析視窗。對話只保留在目前頁面，重新整理或切換情境會重置。

## 固定資料 Demo 的限制

- 對話以情境關鍵字與預設回覆模擬，並非 AI 或理解上下文。回覆方向和提示是情境固定資料。
- 中文查詢只支援 `data/lookup.json` 收錄的詞語，找不到時明確顯示尚未收錄；不提供自由翻譯或完整參考句生成。
- 角色訊息中有底線的預整理詞語可查看原形、中文意思、詞幹、詞尾、文法及例句，並非任意詞語即時解析。

## 本機使用與部署

不需安裝依賴。在專案根目錄啟動 HTTP 伺服器，例如：

```sh
python3 -m http.server 8000
```

瀏覽 `http://localhost:8000/`。情境 JSON 透過 `fetch` 載入，請使用 HTTP 伺服器，不要直接以 `file://` 開啟。部署 GitHub Pages 時，將儲存庫的根目錄設為發布來源即可；所有網站路徑均為相對路徑，也支援 repository 子路徑。

## 新增情境

參考 `data/scenarios/gym.json` 建立 `data/scenarios/<slug>.json`，在 `data/scenarios/index.json` 新增 id、標題、說明及檔案路徑。共用 `chat.html?scene=<slug>` 自動載入該情境。`responses` 的 `keywords` 和 `text` 定義關鍵字回覆，`fallback_replies` 定義輪替的預設備用回覆；`sentence_hints` 提供填空式句型。詞語解析與提示資料沿用現有欄位。詳見 `AGENTS.md`。
